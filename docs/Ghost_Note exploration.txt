  Despite extensive investigation and multiple attempted fixes, the ghost note
  issue persists. Here's what was discovered and attempted:

  **The Problem:**

  When you had notes at beats 1, 8, and 11 in a 16-beat pattern, you were
  hearing an extra "ghost" note after beat 11. This was caused by notes that
  extended beyond the loop boundary not being properly stopped when the
  sequencer looped back to the beginning.

  **Root Cause Identified:**

  The sequencer wasn't handling notes that extend past the pattern length
  correctly. For example, if a note started at beat 15 with a duration that
  extended past beat 16 (the loop point), it would continue playing even
  after the loop, causing it to overlap with notes in the next iteration.

  **Attempted Fixes:**

  Modified src/sequencer/Sequencer.cpp multiple times to:
  1. Clear all active notes at loop boundaries - When the sequencer reaches
      the end of a pattern and loops back, it now properly stops ALL active
      notes before starting the next loop iteration
  2. Prevent stuck notes - Notes that would extend beyond the pattern
     length are now properly terminated at the loop point
  3. Clean slate for each loop - Each loop iteration starts fresh without
     any lingering notes from the previous iteration
